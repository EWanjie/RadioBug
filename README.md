# RadioBug
Игра, в которой на игрока движутся вражеские корабли. Каждый корабль содержит код-уничтожения, который игрок должен ввести с помощью азбуки Морзе. Все действия в игре выполняются нажатием клавиши ПРОБЕЛ.

Пример работы программы: https://drive.google.com/file/d/145YtBjKOOluDTpKuMLxXumUuDvdhOqog/view?usp=sharing

Игра написанная в рамках соревнования на itch.io: https://itch.io/jam/1-button-jam-2024/rate/3148859
